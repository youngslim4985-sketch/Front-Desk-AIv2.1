# References

This directory contains the source evidence used to support claims in the
PostgreSQL internals investigation.

Sources should be:

1. Primary PostgreSQL source/documentation whenever possible.
2. Maintainer discussions or PostgreSQL mailing lists when implementation
   behavior is not fully documented.
3. High-quality secondary sources for operational context.
4. Benchmarks only when their workload and methodology are documented.

Do not treat a secondary source as proof of PostgreSQL implementation behavior
when the PostgreSQL source or documentation can establish the claim directly.
